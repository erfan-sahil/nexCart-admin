# NexCart Admin

React dashboard for NexCart platform operations.

## Stack

- Vite
- React 19 + TypeScript
- Tailwind CSS v4
- shadcn/ui

## Scripts

```bash
npm run dev        # http://localhost:5174
npm run build
npm run preview
npm run lint
npm run typecheck
```

## Add UI components

```bash
npx shadcn@latest add table
```
